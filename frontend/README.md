# Dataflow Web

Vue 3 + TypeScript + Vite + Element Plus。所有生产业务请求均访问 Java `/api`，浏览器不直接访问 Python、RabbitMQ 或 MinIO。依赖精确版本及完整依赖树见 package.json / package-lock.json。

```sh
npm ci
npm run dev
npm run build
npm test
```

Vite 开发模式默认将 `/api` 代理至 `http://localhost:8080`；Compose 的 Nginx 则代理至内网 `backend:8080`。推荐 Node 24；Docker 镜像版本已固定。单元测试使用 Node 内置测试工具与 TypeScript 类型擦除，不需要额外测试依赖。

## 页面行为

- 工作台上传前通过 Web Crypto 计算完整 SHA-256，服务端再次核验；分片和完成使用独立 uploadId。访问地址需要 HTTPS 或 localhost，才能使用 Web Crypto。
- 上传完成不等于解析成功。解析失败保留原始文件，可调整 CSV 编码、分隔符、缺失标记，或选择 XLSX 工作表后重试。字段推断只是样例建议，可使用稳定字段 ID 配置读取类型覆盖。
- 默认预览行数及最大预览数读取当前平台设置。预览只保证样例有效，完整执行仍会校验全部文件及容量。
- 修改解析选项后必须先重新解析，才能创建任务。解析设置、字段、规则、平台限额在任务创建时生成快照，重试不采用后续修改。
- 编辑器保留配置序号，同时展示真正的执行阶段和顺序：规范化、类型转换、缺失值、异常值、校验、去重、最终字段映射；同阶段保持配置顺序。
- 规则参数使用具有显式类型的标量编辑器，区分文本、数字、布尔与 null。验证策略支持移除行、保留并标记、任务失败，范围与 IQR 还可将异常字段置空。
- 脏数据按违规明细保存：一条原始行可能对应多条违规。报告分别显示唯一违规行数、移除行数、保留标记行数和违规条数；守恒关系为输入行数 = 输出行数 + 移除行数。
- 日志按游标增量读取，每轮至多 5 页，最多保留最近 2,000 条；积压日志自动续读，也可手动加载。切换任务隔离旧请求。
- 管理员可管理账户角色与启停、查看所有任务和下载产物、修改 9 项处理限额。其他用户任务不显示取消或重试按钮，后端仍负责最终权限校验。

## 组件边界

`App.vue` 管理会话、工作区、规则版本和任务提交；`FilePanel.vue` 负责上传、解析、预览与字段覆盖；`RuleEditor.vue` 负责规则参数及执行顺序；`AdminConsole.vue` 负责管理员能力；`TaskDetail.vue` 负责日志、报告、快照、操作及下载。`api.ts` 统一鉴权、超时与下载处理。平台限额和规则语义由真实后端提供并验证。

## 验证

`npm run build` 同时运行严格类型检查和生产构建。`npm test` 覆盖执行阶段排序、阶段内稳定顺序、单侧边界、整行 keep-last，以及 0 / false / null / 空串与非法无穷值等规则参数边界。完整业务联调及浏览器端到端验收位于项目根目录 tests / scripts。
