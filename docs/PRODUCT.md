# 产品设计

面向分析师、运营与数据工程师，以真实文件和可追溯规则替代重复清洗脚本。完整流程：上传文件 → 校验完整性 → 配置解析与字段 → 预览 → 保存规则版本 → 提交任务 → 后台执行 → 查看日志 / 报告 → 下载结果和脏数据。Java 是浏览器唯一业务入口。

## 用户和页面

普通用户只能访问自己的文件、规则、任务、日志和产物。管理员可管理用户角色与启用状态、查看全部任务、调整系统限制。服务端对每项操作校验角色或归属；管理员的普通工作台仍处理自己的资源。初始管理员通过部署环境配置，不提供默认密码、不允许注册时选择角色；禁止禁用或降级最后一个有效管理员。禁用用户后已有会话立即失效。

工作台提供上传、解析、规则和提交操作，任务中心展示状态与历史，规则库管理不可变版本，管理页面配置系统。桌面和窄屏都保留导航、退出及错误反馈。任务详情展示本次尝试、固定版本和快照、增量日志、输入 / 输出 / 删除 / 有问题记录与错误明细计数。

## 上传和解析

上传会创建不同的 fileId 与 uploadId；分片可安全重传，完成时验证分片数量、长度及完整 SHA-256。服务器始终计算最终摘要，浏览器提交期望摘要后服务器必须核对。原始内容存 MinIO，元数据和摘要存 MySQL。24 小时未完成上传定期清理。

上传完成仅代表 raw 对象已保存。解析单独显示 UNPARSED / PARSED / FAILED 和错误原因，解析失败的文件可以修改参数重试，不能直接创建任务。解析依赖真实读取器校验内容，不只检查后缀；预览不承诺完整文件通过全部执行限制。

CSV 支持自动识别和手动设置编码 / 分隔符，可配置缺失标记；自动识别不确定时明确提示用户调整。XLSX 展示工作表并默认选择第一张，用户可以选定其他表；每次只处理选中表。Parquet 仅接受扁平标量结构。预览默认前 100 行（按系统配置），显示原列名、稳定字段 ID、样例、推断类型及样本缺失数。推断只是建议；手机号、邮编、证件号可显式保留字符串，避免前导零丢失。

页面展示系统实际文件、行列、单元格、Excel 展开体积及预览限制。管理员只能在经过验证的硬上限内调整，超出容量需要修改代码并重新做资源验证。

## 清洗和追溯

默认执行阶段固定为：字符串规范化 → 类型转换 → 缺失处理 → 异常处理 → 数据校验 → 全任务去重 → 输出字段选择 / 重命名。同阶段保持用户数组顺序，页面展示实际执行顺序。规则引用原始位置生成的稳定 ID（f0、f1…），最终重命名不会破坏前面的规则引用。

支持字段保留 / 删除、改名、字符串操作、整数 / 数值 / 日期 / 布尔转换、格式与精度、固定或统计填充、组合 / 整行去重、范围 / IQR 异常、非空 / 枚举 / 长度 / 正则 / 类型 / 声明式比较校验。每种规则的参数、空值和统计语义见 [RULES.md](RULES.md)。不允许提交 Python、SQL、Java 或 shell 代码。

规则版本及完整规则、解析参数、字段和处理资源限制快照在任务创建时固定，后续修改不改变已有任务和重试的处理语义。重新申请任务或重试仍受当前账号状态、并发与频率限制。V1历史任务首次重新入队时，从已有规则版本、当时文件和系统配置补齐一次快照。任务取消、失败重试及Worker租约恢复沿用可持久化的异步执行机制。

## 脏数据和报告

规则可删除违规记录、保留并标记，或使任务明确失败；异常值还可替换为缺失并记录问题。同一行可以有多条错误，脏数据 CSV 每个错误一条，含原始记录标识、字段、规则编号、错误码和原因，原始单元格不被清洗后的值覆盖。

验证阶段先收集该阶段所有失败原因再统一删除；已经离开处理集合的行不参与后续阶段和统计。标记行保留在结果，附带质量字段。报告区分 `removedRows`（删除行数）、`dirtyRows`（有问题的独立记录数）、`flaggedRows` 和 `issueCount`（错误条数），因此以 `inputRows = outputRows + removedRows` 校验守恒，不能把错误条数当成删除行数。

## 验收与范围

使用 Compose 的真实 Java / Python / MySQL / MinIO / RabbitMQ 完成 CSV、XLSX、Parquet 读写和授权下载；测试包括普通用户越权、管理员限制、分片摘要、解析配置、规则快照、统计边界、多原因策略、队列中断和 Worker 退出恢复。具体命令及实测证据见 [TESTING.md](TESTING.md)。

平台保持单机内存清洗架构，单 Worker 执行一个任务。暂不引入 Kafka、分布式计算、工作流引擎和多租户组织系统；多节点扩展前需统一上传暂存、并发锁和服务发现。当前容量边界与运维限制详见部署文档。
